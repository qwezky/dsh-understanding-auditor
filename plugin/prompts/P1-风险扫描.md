# P1 · 理解风险扫描（建 DAG + 按 lineage 标来源 + 列风险点）

> 输入：`handoff.json` 的 `report_text`、`lineage`、`retention_index`、`recording`、`dial`。
> 输出：一个 JSON 对象。**只标风险，不判对错，不出题。**

## 输入处理

1. 先检查：`report_text` 少于 80 字、或没有可独立成立的论断（纯背景、纯引用、纯目录）→ 输出
   `{"error":{"code":"INPUT_TOO_THIN","message":"这段更像背景铺垫，换一段有论点的（80 字以上、建议 150 字以上，含至少一个可成立的判断）。"}}`
2. 提示用户自行删除姓名、学号、导师、未公开项目名；**不要**在输出里复述任何个人信息。
3. `recording.complete = false` 或 `gaps` 非空时：**不要假装来源完整**。没有 `lineage` 覆盖的节点一律按 `unknown`，并在 `origin_basis` 里写“记录不完整”。

## 来源判定（v1.9 核心）

只看 `lineage` 里的真实事件，不看“用户读过/审阅过”：

| 情形 | `origin` | `provenance` |
|---|---|---|
| `author: user` 的正文/附件/粘贴（不是写作指令） | `human` | `user_source` |
| `author: ai`，但用户有 `event: rewrite` | `human` | `user_note` |
| 用户重写了 AI 摘要（`user_note_id` 非空） | `human` | `user_note` |
| 只有 `author: ai` 的片段，用户没重写 | `ai` | `ai_summary` |
| 只有 `author: external`（联网/检索/工具返回） | `ai` | `external` |
| 用户只给了写作指令、或只审阅过 | `ai` | `unknown`（指令不是知识） |
| 报告里有、谱系里没有、索引也没有 | `ai` | `unknown` |
| 同一概念两处都有 | `human` + `ai_variant: true` | 以用户来源为准，AI 版本进抽查池 |

**默认从严**：拿不准就 `ai` / `unknown`。`retention_index` 只做交叉校验，不单独决定 `origin`；`self_rating` 只用于复习排序，不是来源。

## 建图规则

- 抽 **5–12 个节点**，覆盖报告的核心论证链，不逐句抽。
- 节点 `kind`：`claim` 可独立成立的判断 / `term` 反复使用但没定义的概念 / `reason` “因为—所以”中的一步 / `evidence` 数据、案例、引文 / `conclusion` 带条件的结论。
- 边方向统一为**前置 → 后继**：`A → B` 表示“要理解 B，得先理解 A”。节点上同时写 `parents`（前置）与 `children`（后继），三者必须自洽。
- **入口**是 `children` 为空的论断节点（出度为 0）；`entry_ids` 至少 1 个。
- **环**：先做 SCC 折叠，环内节点合成一个概念簇，簇整体只问一次；`cycles` 留档。折叠后不得再有环。
- **分量**：按弱连通分量分组，`components[].node_ids` 必须覆盖全部节点，且每个节点只属于一个分量；`entry_ids` 是该分量内的入口。
- `level` 由拓扑排序得到（无前置为 1），只用于展示，不用于遍历顺序。
- `risk`：`high` 承载核心结论且无定义/无引文；`mid` 反复出现但未解释；`low` 有引文或已解释。
- `non_prereq_links` 只放 `contrast` / `example` / `supports`，不参与推断。

## 风险点（最多 5 条）

每条必须能落到一个节点，并带**逐字**原文引用。按“最可能讲不出”的程度排序，优先：
1. 承载核心结论、但没说明机制的 `claim`；
2. 全文反复使用、从未定义的 `term`；
3. 依赖隐含前提、换前提就可能不成立的 `conclusion`。

## 自检（输出前逐条过，不写进 JSON）

- [ ] 每个 `quote` 都能在 `report_text` 里原样检索到
- [ ] 每个节点都有 `origin` 与 `provenance`；没有 lineage 依据的节点是 `ai` / `unknown`
- [ ] `recording.complete = false` 时，没有把未覆盖节点写成 `human`
- [ ] 每条边都满足 `parents` / `children` 对称
- [ ] 没有环；每个节点恰属于一个分量；入口 `children` 为空
- [ ] `risk_points` ≤ 5，且每题类型只在三类内
- [ ] 没有出现“对/错/分数/查重/AI 率”等判定或评价词
