# P2 · 出题（三类反向题）

> 输入：`graph`、`budget`（本轮的档位与题量）、`dial`、`mode`、`asked`（已问题目/节点）、可选 `target`（抽查或补全回访的节点）。
> 输出：一个 JSON 对象，只含 `questions` 数组。**不判对错、不写答案。**

## 输入字段

```json
{
  "graph": { "nodes": {}, "edges": [], "components": [] },
  "entry_ids": ["R1"],
  "budget": [
    { "component_id": "G-01", "entry_id": "R1", "tier": "normal", "count": 2, "reason": "AI 入口，核心结论无引文" }
  ],
  "dial": 3,
  "mode": "first_pass | upgrade | spot | variant",
  "asked": [{ "node_id": "R1", "type": "复述解释题", "quote": "……" }],
  "target": { "node_id": "T3", "entry_id": "R1", "tier": "normal" },
  "variant_of": "Q2",
  "original_quote": "被跳过原题的引用句"
}
```

## 通用出题规则

1. **题型三选一**，不得出现第四类：
   - `复述解释题`：抽 `claim` / `reason`，要求**不用**原文关键词，解释意思与成立理由；
   - `前提变换题`：抽隐含前提/适用条件，改变**一个**前提，问结论是否还成立、为什么；
   - `术语定义题`：抽 `term`，要求用自己的话定义，并说明与相近概念的区别或在本文中的具体所指。
2. **一题一问**：问号不超过 2 个；题干不得出现“请判断对错”“下列说法是否正确”，不得把答案或 `expected_points` 写进题干。
3. **quote 逐字**取自 `report_text`，优先选能定位到段落的完整句；同一轮不同题不得复用同一 quote（`variant` 模式必须换引用句）。
4. **rubric 必须可判**：`expected_points` 2–4 条，每条是一个可观察的要点；`must_not` 1–3 条，写常见错误或与原文冲突的说法。
5. **不超纲**：题干与期望要点只能由 `quote` 与报告推出；报告没讲清的，期望要点写“指出报告没有展开这一点”，不要补外部知识。
6. **难度**只写 `低` / `中` / `高`，由节点 `risk` 与 `dial` 决定。

## 档位规则

- `simple`：只给 `human` 入口，1 题；优先该入口分支里出现频次最高的 `term`，没有术语就考入口论断的复述；难度不超过 `中`。
- `normal`：给 `ai` 入口，或简单档没过关后升级的 `human` 入口，2–3 题，至少覆盖两类题；**第一题必须是入口题**（考入口论断或它最核心的术语）。
- `budget[].count` 是硬上限；总题量不得超过本轮预算。

## 各 mode 的额外约束

| mode | 出几题 | 额外要求 |
|---|---|---|
| `first_pass` | 按 `budget` 合计 | 覆盖各入口；类型轮换，每类 ≤2 |
| `upgrade` | 2 | 只沿失败入口的 `parents` 补题，不重复 `asked` 里的节点；优先“复述 + 前提”或“复述 + 术语” |
| `spot` | 1 | 只考 `target.node_id`；换一种问法，不复用原句；`spot_check: true` |
| `variant` | 1 | `variant_of` 指向被跳过的原题 id；`original_quote` 是被跳过原题的引用句，**新 quote 必须与它不同**；必须换题型或换角度，只考被跳过的节点 |

## 输出 schema

```json
{
  "questions": [
    {
      "id": "Q1",
      "mode": "first_pass",
      "variant_of": null,
      "type": "复述解释题",
      "tier": "normal",
      "entry_id": "R1",
      "component_id": "G-01",
      "node_id": "R1",
      "dial": 3,
      "spot_check": false,
      "skip_allowed": true,
      "quote": "该方案通过过程性追问提升学生的认知参与度。",
      "question": "请不用“过程性追问”“认知参与度”这两个词，解释这句话在说什么，并说明它为什么可能成立。",
      "rubric": {
        "expected_points": [
          "追问发生在学习过程中，而不是学习结束后",
          "追问迫使学生把思路说出来",
          "思路外化之后才可能被教师调整"
        ],
        "must_not": ["把追问等同于普通课堂提问", "声称追问能直接提高考试分数"]
      },
      "followup": "你能用“因为—所以”再讲一遍吗？",
      "difficulty": "中"
    }
  ]
}
```

## 自检（输出前逐条过，不写进 JSON）

- [ ] 每题 `type` 只在三类内；`tier` 只在 `simple` / `normal`
- [ ] 每题 `quote` 都能在报告里原样检索到
- [ ] 没考报告以外的知识；没泄露答案；问号 ≤2
- [ ] `simple` 只给 `human` 入口且 1 题；`normal` 第一题是入口题
- [ ] `variant` 的 `quote` 与原题不同，`variant_of` 已填
- [ ] 题量没超过 `budget` 合计；同一节点没有重复出题
