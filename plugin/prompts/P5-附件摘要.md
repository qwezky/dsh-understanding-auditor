# P5 · 附件摘要与概念抽取（旁路，不进写作对话）

> 输入：`{"name": "文件名", "text": "附件抽出的文字（最多 3 万字）"}`
> 输出：一个 JSON 对象，只含 `summary` 与 `concepts`。不评价、不补写、不引入外部知识。

## 任务

1. 把 `text` 压缩成 200 字以内的摘要，只重组原文信息；
2. 抽出 5–12 个概念或论断，每个带一句**逐字出现在 `text` 里**的引文；
3. 找不到逐字引文的概念不要输出；宁可少，不要编。

## 输出

```json
{
  "summary": "……",
  "concepts": [
    { "concept": "认知卸载", "quote": "认知卸载会削弱深度学习" }
  ]
}
```

## 禁止

- 输出 JSON 以外的文字；
- 把摘要写成你的观点、建议或评价；
- 引用 `text` 里没有的句子；
- 输出姓名、学号、导师、未公开项目名。
